AGENCYKEY RECORDER TESTS - CHROME - WINDOWS 64 BITS

1. Descarga AgencyKeyRecorderTests.exe desde Releases del repositorio privado.
2. Guardalo en una carpeta propia y abrelo con doble clic.
3. Requiere Google Chrome ya instalado. No necesita Python ni OBS.
4. Selecciona 5 para generar una demo local. No descarga Chromium ni
   otro navegador, ni descarga codificadores durante el primer uso.
5. Usa 1 para configurar posts existentes, 2 para iniciar sesion en AgencyKey,
   3 para grabar y 4 para enviar el video al bot de pruebas. 0 cierra la app.

Chrome se abre en una ventana con una sesion separada del grabador.
No utiliza ni modifica el perfil personal de tu Chrome habitual.
Durante la prueba Chrome permanece visible. Si falla, revisa la consola y
el navegador antes de pulsar Enter para cerrarlo. report.json conserva la
etapa del fallo, los IDs comprobados y el estado de carga de las imagenes.
El video sigue siendo un MP4 continuo a 480p.

Datos y videos: %LOCALAPPDATA%\AgencyKeyRecorderTests
El programa muestra la ruta exacta al abrir. Se conservan al actualizar el EXE.
El token de Telegram se pide al enviar y no se guarda.

Usa el nuevo EXE en lugar de la version anterior para evitar sus descargas.
Esta version no utiliza la carpeta browsers descargada por el EXE anterior;
no la borra automaticamente.

Dropper permanece intacto. La prueba real de AgencyKey requiere tu sesion.
Este EXE mantiene el menu de consola y no incluye activacion por fin de Drop.
